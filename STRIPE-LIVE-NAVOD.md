# Stripe: переход с sandbox на приём реальных платежей

## Важно понимать

Сейчас магазин подключён к **sandbox-аккаунту** `Little One Store sandbox` (acct_1Tqslr…).
Sandbox — это отдельная тестовая песочница, её **нельзя «переключить» в боевой режим**.
Для реальных платежей нужен настоящий Stripe-аккаунт компании **Azruk s.r.o.**

Код магазина уже полностью готов к боевому режиму — менять ничего не нужно.
Переход = активация аккаунта + замена двух ключей в Vercel.

## Что должна сделать клиентка (я это сделать не могу — там паспорт и банковский счёт)

### Шаг 1. Активировать аккаунт
1. Зайти на https://dashboard.stripe.com — тем же логином, но **выйти из sandbox**
   (переключатель аккаунта слева вверху → выбрать реальный аккаунт, не «sandbox»).
   Если реального аккаунта нет — «Create account», страна **Czech Republic**, валюта **CZK**.
2. Нажать **Activate payments / Aktivovat platby** и заполнить:
   - тип бизнеса: Company → s.r.o.
   - название: **Azruk s.r.o.**, IČO **14420333**, DIČ **CZ14420333**
   - адрес: Hviezdoslavova 545/41, 627 00 Brno
   - вид деятельности: retail / e-commerce — детская одежда
   - сайт: https://www.littleonestore.cz
   - данные представителя (паспорт/ID) — требование закона, вводит только клиентка
   - **банковский счёт** для выплат: 7441532004/5500
3. Дождаться подтверждения Stripe (обычно от нескольких минут до 1–2 дней).

### Шаг 2. Взять боевые ключи
В боевом аккаунте (переключатель **не** в режиме Test):
Developers → API keys → скопировать **Secret key** (начинается с `sk_live_…`).

### Шаг 3. Создать боевой webhook
Developers → Webhooks → **Add endpoint**:
- URL: `https://www.littleonestore.cz/api/stripe-webhook`
- События: `checkout.session.completed`, `checkout.session.expired`,
  `checkout.session.async_payment_failed`
- После создания скопировать **Signing secret** (`whsec_…`).

### Шаг 4. Заменить ключи в Vercel
Vercel → проект **miadelka-store** → Settings → Environment Variables:
- `STRIPE_SECRET_KEY` → новый `sk_live_…`
- `STRIPE_WEBHOOK_SECRET` → новый `whsec_…`
Затем Deployments → последний деплой → **Redeploy** (чтобы подхватились новые ключи).

### Шаг 5. Проверка
Сделать один реальный заказ на маленькую сумму своей картой:
- платёж должен пройти,
- заказ в админке получить статус **Zaplacená**,
- письма клиенту и на info@littleonestore.cz должны прийти,
- деньги появятся в Stripe → Balance (выплата на счёт обычно через 7 дней после первого платежа).

## Что уже готово в коде
- ✅ Stripe Checkout Sessions (карта, Apple Pay, Google Pay), валюта CZK
- ✅ Проверка цен на сервере — клиент не может подменить сумму
- ✅ Webhook: заказ → «Zaplacená», списание со склада, письма
- ✅ Скидочные коды и подарочные сертификаты как Stripe-купоны
- ✅ Способы доставки с ценами передаются в Stripe как shipping_options

⚠️ Пока ключи тестовые — на сайте принимаются **только тестовые карты**. Реальная карта
даст ошибку. Поэтому шаги 1–4 нужно сделать до запуска рекламы.
